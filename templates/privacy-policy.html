Privacy Policy

Last updated: August 2026

🔒 100% Client-Side Privacy Guarantee:
All file conversions (PDF, Word, Images, OCR), ATS resume scoring, resume building, and bulk HR candidate screening run 100% locally inside your web browser. Your private documents, images, and CVs are NEVER uploaded to any remote server or external cloud storage.

AuraToolkit360 operates as a client-side browser web application. We do not collect, store, or transmit your personal documents, resumes, or uploaded files. All text extraction, file conversion algorithms, and ATS keyword matching execute in your device's memory using modern WebAssembly and JavaScript technologies.
