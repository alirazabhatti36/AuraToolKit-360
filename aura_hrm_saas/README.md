# TeamHatch360
**Complete B2B Multi-Tenant HR, ATS & Biometric Payroll SaaS Platform**

TeamHatch360 is an enterprise-grade B2B Human Resource Management (HRM) and Applicant Tracking System (ATS) platform powered by multi-tenant company isolation, Firebase Cloud integration, Hikvision biometric attendance sync, automated payroll processing, asset inventory tracking, and Super Admin SaaS management.

## Features
- **Multi-Tenant Architecture**: Strict company-level data isolation across all HR, ATS, and Payroll modules.
- **Super Admin SaaS Portal**: Register, monitor, and manage B2B client companies and subscription limits.
- **Applicant Tracking System (ATS)**: Resume parsing, keyword scoring, candidate pipeline management.
- **Biometric Attendance**: Integrated Hikvision local bridge sync (`hikvision_bridge.py`).
- **Payroll & Increment Management**: Allowances, tax deductions, cash/bank salary splits, increment workflows.
- **Asset Inventory**: Laptops, cards, and office asset assignment tracking per employee.
